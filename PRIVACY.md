# Privacy policy for local-ai-assistant

This is a personal, single-user application run by its owner on private
hardware. It accesses the owner's own Gmail and Google Calendar data only to
read messages and events, save drafts, and send messages the owner explicitly
approves.

The data is processed on the owner's own machines. It is not shared with
anyone, not sold, and not used for advertising or any other purpose.

Questions: open an issue in this repository.
